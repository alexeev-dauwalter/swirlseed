Install
One algorithm, three ways to use it. The TypeScript package and the Rust crate render the exact same bytes for the same seed.



  
npm
Browser or Node. ESM, no dependencies.
npm install swirlseed
npmjs.com/package/swirlseed →

  
Rust crate
Library with zero dependencies (optional NFC feature).
cargo add swirlseed
crates.io/crates/swirlseed →

  
CLI
Writes PNG files with the same options as the generator above.
cargo install swirlseed-cli
crates.io/crates/swirlseed-cli →
