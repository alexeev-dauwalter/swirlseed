Install

One set of algorithms, three ways to use it. The TypeScript package and the Rust crate render the exact same bytes for the same seed and parameters.

npm

Browser or Node. ESM, no dependencies. generate() for the swirl, renderGenerator() for the rest.

npm install swirlseed
swirlseed 0.2.0 on npm →

Rust crate

Library with zero dependencies (optional NFC feature). Every generator lives in swirlseed::gen.

cargo add swirlseed
swirlseed 0.2.0 on crates.io →

CLI

Writes PNG files. swirlseed --list shows every generator and its parameters.

cargo install --locked swirlseed-cli
swirlseed-cli 0.2.0 on crates.io →
